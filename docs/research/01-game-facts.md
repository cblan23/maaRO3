# RO3 玩法、日常与操作事实库

> 版本：research-v0.2，基准日期 2026-07-28。
> 本文描述的是“目前公开资料能证明什么”，不是国服正式攻略。除国服招募公告外，大部分细节来自 2026-06-25 至 07-02 台港澳“启燃测试”，官方已说明该技术测试把每日、每周和活动压缩开放，后续会调整。

## 1. 阅读标记

| 标记 | 含义 | 可否直接写成业务规则 |
|---|---|---|
| `CN-A` | 国服官方公告、协议或制作人原文 | 仍需按客户端版本复核 |
| `GL-A` | 全球／台港澳官方资料 | 不能直接替代国服规则 |
| `TEST-B` | 启燃测试玩家完整录像、截图或一手长文 | 只能作为采样假设 |
| `C` | 媒体转述或多源互证 | 只用于发现线索 |
| `UNKNOWN` | 目前没有足够画面或原文 | 禁止猜测实现 |

所有等级、次数、时段、坐标、快捷键、重置时间和收益比例都属于易变字段。未来记录必须至少携带 `region + channel + build_id + captured_at + ui_profile`。

## 2. 游戏类型与核心循环

已确认的产品定位是 PC 优先、兼顾移动端互通的社交 MMORPG。国服 2026-08-27“重逢测试”只开放 Windows PC；测试为限号、不计费、删档。[国服招募公告](https://www.taptap.cn/moment/828585152161515154) `CN-A`

当前资料显示的循环不是 MaaKES 那种“进入一局—按固定地图推进—结算退出”的封闭流程，而是持续在线的开放世界：

```text
角色成长
  ├─ 主线／支线／委托推进
  ├─ 开放地图选怪、打怪、卡片与图鉴
  ├─ 游戏内建辅助战斗与队伍挂机
  ├─ 五人副本、十人 RAID、MVP、裂隙
  ├─ 生活职业、采集、制作与公会物资
  └─ 摆摊、拍卖、公会活动、PVP／GVG
```

研发方还计划以季度主题或赛季持续更新。任何“完整日常表”都只能是构建快照，不能成为永久平面路由。[开发日志报道](https://gnn.gamer.com.tw/detail.php?sn=305589) `GL-A/B`

## 3. PC 操作与界面

### 3.1 操作模式

启燃测试首日画面展示了三种模式：

| 模式 | 画面可确认的主要移动方式 | 当前可信度 | 国服待确认 |
|---|---|---:|---|
| 经典模式 | 鼠标左键点击地面移动 | `CN-A + TEST-B` | 点击、锁敌、交互是否同键；拖拽时行为 |
| 现代模式 | WASD 移动，鼠标参与朝向／交互 | `TEST-B` | 完整键位和能否自定义 |
| 行动／手机模式 | 旧测试画面有入口但当时不可选 | `TEST-B` | 国服 PC 是否保留 |

视觉证据见 [48 秒关键帧](../../research/evidence/video/day1-guide-bv1yqtk6oekk/frames/0048-control-mode-selection.png)。国服制作人信也明确提及 PC 鼠标点击移动、人物走位和怪物锁敌。[制作人的信](https://www.taptap.cn/moment/828606077506422297) `CN-A`

### 3.2 快捷键线索

启燃测试攻略录像称：

- `Z` 曾作为游戏内建自动战斗开关；
- 右键可进入自动战斗技能设置；
- 主快捷栏还出现数字键和组合键提示；
- 游戏菜单中部分功能旁显示快捷键。

这些属于 `TEST-B` 快照。[自动战斗设置帧](../../research/evidence/video/test-closeout-bv1ybny6feze/frames/0107-auto-battle-settings.png)进一步证明配置窗会列出技能类别、技能和等级。一名[测试玩家](https://forum.gamer.com.tw/C.php?bsn=81475&snA=73)报告当时内挂只施放六格热键栏中的技能、战斗中不能更换栏位，猎人的内挂施放速度还可能低于手动；这是单一玩家行为证据，不是所有职业的已确认规则。国服首测必须在设置页逐项截图并人工按键验证，不能从字幕或评论直接生成键盘动作。

### 3.3 UI 可重排

制作人明确说明大部分 PC 窗口可以拖动、缩放，聊天框可自由摆放；启燃录像还展示设置中的 UI 缩放。新增 TEST-B [自订布局编辑器父帧](../../research/evidence/video/twitch-vod-2805774434/frames/15914.00-custom-layout-editor.jpg)直接显示 HUD 控制框可拖移、全部／常驻／提示／战斗筛选和恢复预设入口，但没有保存、取消或恢复后的连续结果。[制作人的信](https://www.taptap.cn/moment/828606077506422297) `CN-A/TEST-B`

直接设计后果：

- 不能把公开视频中的绝对坐标当作模板坐标；
- 需要记录 DPI、分辨率、窗口／全屏模式、UI 缩放和各浮窗位置；
- 识别应优先使用稳定锚点与相对 ROI；
- 每次运行前应检测布局指纹，不匹配时停止；
- 如果允许用户自由布局，应提供“支持的标准布局”或重新标定流程。

### 3.4 常驻 HUD

当前录像常见区域包括：

- 左上：头像、Base／Job 等级、HP／SP、队伍入口；
- 左侧：建队、入队、寻队入口；
- 左下：聊天标签、输入栏、角色／技能快捷提示；
- 下方：技能和消耗品快捷栏；
- 右上：小地图、时间、频道／地图信息；
- 右侧：成长徽章、主线／支线追踪和活动入口；
- 右下：角色、技能、背包等主菜单入口。

它们会随 UI 缩放、窗口拖动、队伍状态、剧情和玩法发生变化，不能当作一张静态主页。

## 4. 角色成长与系统开放

### 4.1 职业

启燃测试确认六个基础职业和七个已展示的三转终点：

| 基础职业 | 当前已确认的三转终点 |
|---|---|
| 剑士 | 卢恩骑士、皇家禁卫队 |
| 魔法师 | 咒术士 |
| 服事 | 大主教 |
| 弓箭手 | 游侠 |
| 盗贼 | 十字斩首者 |
| 商人 | 机械工匠 |

来源：[GNN 启燃测试实机](https://gnn.gamer.com.tw/detail.php?sn=307340) `TEST-B`。未出现的贤者、武僧、流氓、诗人／舞娘、炼金等路线不能自行补入国服首测清单。

### 4.2 养成维度

已公开的维度包括六维属性、技能、装备、精炼、卡片、主战宠物、助战宠物、天赋、灵魂残响和流派手册。流派手册用于保存并分享整套配置。[启燃测试落幕报道](https://news.pchome.com.tw/game/ldplayer/20260713/index-78393333464536345104.html) `GL-A/B`

TEST-B 精炼实机采用按装备部位列等级的页面，选中槽位后同时显示下一等级、成功率、属性变化、材料与来源：[槽位精炼](../../research/evidence/video/refine-ui-bv19htn6peo2/frames/0182-refine-slot-level.png)、[材料来源](../../research/evidence/video/refine-ui-bv19htn6peo2/frames/0212-refine-material-sources.png)。它适合未来生成只读缺口报告，但成功率、材料、货币和换装继承都必须国服复验，精炼本身始终排除自动执行。

如果未来取得授权，助手应选择玩家事先保存的流派，而不是自行做不可逆加点、精炼、宠物抽取或换装决策。

## 5. 主线、委托与自动寻路

### 5.1 主线／支线

右侧任务追踪显示主线、支线、好友等项目。玩家录像普遍通过点击任务追踪触发寻路或继续对话。需要区分：

1. 点击追踪；
2. 游戏内自动寻路／移动；
3. 到达后对话、交物、战斗或剧情；
4. 任务完成、接取下一环或被等级门阻断。

当前仍缺少国服对“正在寻路、路径中断、传送、跨地图加载、NPC 被遮挡、剧情选择”的完整状态样本。

### 5.2 呆呆的委托

启燃测试每日面板称“完成呆呆发布的委托任务，获得大量经验”，并有 `前往` 入口。玩家长文称其大部分过程依赖游戏内自动寻路／自动流程；另一份玩家建议称一项任务会跑五个地点、往返约十趟。后者是体验描述，不是完整录像计数。`TEST-B`

候选状态序列：

```text
每日面板 → 前往／NPC → 接取 → 游戏内寻路
→ 交互／击杀／采集 → 交付 → 下一环或完成
```

未确认项包括每日环数、是否自动接下一环、背包要求、跨图失败、剧情跳过、组队状态和最终完成标志。

首日关键帧显示页面包含“必做／周常”标签、任务条目、活跃度、阶段宝箱和右侧限时活动。随着升级，面板会继续加入 MVP、野外挂机等任务：

- [每日面板，392 秒](../../research/evidence/video/day1-guide-bv1yqtk6oekk/frames/0392-daily-panel.png)
- [扩展后的每日面板，466 秒](../../research/evidence/video/day1-guide-bv1yqtk6oekk/frames/0466-daily-panel-expanded.png)

### 6.1 启燃测试日常快照

| 内容 | 玩家实际操作 | 可见进度／结束信号 | 易变风险 |
|---|---|---|---:|
| 呆呆委托 | 前往、接任务、跟随游戏内寻路、交互／击杀、交付 | 环数、完成标记、活跃度 | 高 |
| 公会商队／物资 | 打开需求页，从库存装载所需物资 | 单批已有 `7/8 → 8/8 → 奖励 → 2/4`；第四批另见 `4/8` 发车禁用 → `5/8` 发车可用，但点击后终局与每日变化仍未知 | 高 |
| 生活玩法 | 选择生活职业行为，消耗活力采集／制作 | 五次各 `-20`，随后每日页 `100/100 已完成` | 高 |
| 精灵之塔／宠物塔 | 编队宠物、挑战逐层内容 | 层数、奖励、失败／通关 | 高 |
| MVP | 进入／组队／攻击野外 Boss | 旧测试曾要求参与 5 个 | 极高 |
| 野外挂机 | 选等级区间、目标怪、是否加倍并开始 | 分钟／累计时长、击杀数、疲劳 | 极高 |
| 阶段宝箱 | 活跃度达到 20／40／60／80／100 后领取 | 20 档已有金色可领 → 过渡 → 绿色已领连续证据 | 高 |
| 限时活动 | 按日历参加营火、狩猎等 | 开放时段、参与／完成 | 极高 |

旧测试画面曾显示“每日 05:00 更新”，但国服重置时间不得据此确定。

### 6.2 时间负担的一手描述

测试玩家总结：登录、委托、采集、交物资、MVP 和挂机可能约两小时；裂隙、活动、副本、宠物塔等另需约两小时。此信息只说明“日常负担可能很长且分散”，不代表稳定耗时。来源：[巴哈启燃测试心得](https://forum.gamer.com.tw/Co.php?bsn=81475&sn=189) `TEST-B`

## 7. 野外打怪、挂机与图鉴

### 7.1 游戏内建自动战斗

官方确认游戏自身具有辅助战斗，设计目标是手动收益更高，辅助收益约手动 70%～80%，用于练级、打怪或临时离开。[制作人采访](https://news.pchome.com.tw/game/gamer/20260129/index-76964660191804203104.html) `GL-A/B`

这只是产品功能，不等于允许外部脚本。当前画面能证明旧测试存在该状态：[自动战斗 HUD](../../research/evidence/video/day1-guide-bv1yqtk6oekk/frames/0333-auto-battle-hud.png)和[技能设置窗](../../research/evidence/video/test-closeout-bv1ybny6feze/frames/0107-auto-battle-settings.png)。论坛中的职业实测还提示：辅助战斗可能只循环热键栏技能，且不同职业的辅助施放效率未必一致。因此 MAA 的高价值工作是检查玩家预先配置、状态、进度和异常，不是另写一套战斗循环去绕过这些产品限制。

### 7.2 野外挂机面板

旧测试面板可见：

- 地图／怪物等级区间下拉框；
- 魔物列表和单个目标选择；
- 加倍剩余分钟与累计上限；
- 加倍规则说明；
- 开始挂机入口；
- 同地图组队可挂机并分享／独立计算部分收益的说明。

证据：[挂机选择页](../../research/evidence/video/day1-guide-bv1yqtk6oekk/frames/0448-farming-panel.png)、[规则说明](../../research/evidence/video/day1-guide-bv1yqtk6oekk/frames/0456-farming-rules.png)。

长直播进一步提供了三个高倍页面变体：[尚有额度 `60分/180分`](../../research/evidence/video/twitch-vod-2805739995/frames/5895.00-farming-boost-available-clean.jpg)、[开启后倒计时 `59分50秒 → 59分40秒`](../../research/evidence/video/twitch-vod-2804892798/manifest.json)和[耗尽 `0秒/180分`](../../research/evidence/video/twitch-vod-2804807809/frames/24411.00-farming-boost-exhausted.jpg)。耗尽页相隔约 24 秒仍保持，说明不是瞬时提示；在这 24 秒中，[奖励通知父帧](../../research/evidence/video/twitch-vod-2804807809/frames/24420.00-farming-boost-exhausted-reward-feed.jpg)还同步出现齿轮、`Base经验 X3` 和`连帽披肩 X1`，且背景有伤害数字。它直接排除“高倍归零必然停战／完全零收益”，但三个高倍变体仍来自不同账号，不能当成同账号完整跨零序列；客户端也没有把该状态标成低倍或疲劳。

旧测试攻略交叉描述：每天 60 分钟加倍，可累计至 180 分钟；疲劳以击杀数量而非纯时长计算。新连续帧只证明高倍耗尽时仍会出现经验、齿轮／分解产物和物品通知，并没有回答掉率或卡片资格。对加倍结束后的掉落仍存在冲突：Day1 图文称一般挂机只有少量经验／基础材料、没有装备或卡片；Day2 连续讲解则称先进入仍可掉基础装备、材料和卡片的低倍阶段，再进入不能掉卡的疲劳阶段；另一名 TEST-B 玩家称一小时结束、角色疲劳后继续挂机“几乎没有任何收益”。最后一句仍是体验口述，“几乎没有”不能改写成零收益，也没有给出客户端状态名。全部标记为 `TEST-B`，阶段名称、转换阈值和奖励集合必须由国服规则页读取，不能选一个攻略写成常量。

[6 分钟连续挂机录像](https://www.bilibili.com/video/BV1FkKd6CEYL/)还显示：卡片获得大遮罩、挂机收益窗和技能／挂机配置窗出现时，背景战斗可能仍在继续。约 02:25 和 04:31 两次出现狸猫卡片，约 02:35 的收益页按距上次查看的时间汇总经验、货币和物品，约 04:36 再打开加倍挂机页。该视频未覆盖加倍归零或疲劳边界，不能用它推断掉率。

### 7.3 挂机运行中需观察的状态

公开视频已见：目标血量、角色血量、技能冷却、伤害数字、目标切换、掉落列表、聊天、队伍、击杀统计、自动战斗图标。

2026-07-26 新发布的 [14 秒卡位片段](https://www.bilibili.com/video/BV1rg376UE6k/)提供了首个同项目 `AutoOnBlockedCandidate` 序列：角色在狭窄走廊边缘约 13 秒没有形成有效位置进展，但朝向／动作轨迹、伤害数字和附近魔物持续变化。作者标题将其描述为“近战职业自动挂机被地形卡住反复左右”；画面能证明的是“未冻结但无位移进展”，不能单独证明自动状态、碰撞原因或所有近战职业都会如此。关键帧见[序列 Manifest](../../research/evidence/video/auto-blocked-terrain-bv1rg376ue6k/manifest.json)。这直接说明卡位检测必须同时看位置、动作、目标／击杀和时间窗，不能把有技能特效等同于流程健康。

新证据还直接显示“HP 低于 70% 时自动使用”的快捷用药勾选态、药品数量 `36 → 35`，以及配置时“背包中没有该道具，无法添加”的反馈。数量变化与启用态相互印证，但录像没有键盘输入可视化，因此自动触发仍需国服受控复测；配置缺药也不等于战斗中最后一瓶耗尽。

仍缺高质量证据的异常包括：

- 野外角色死亡／复活选择；
- 药品从 `1 → 0`、装备耐久或负重；
- 真正满包、卡片掉落被阻断；
- 怪物离开范围、没有合适目标；
- 队长离队、队伍解散、跨线；
- 网络断线、重连、维护、版本更新；
- 高倍非零跨零、耗尽后的阶段名／掉率、疲劳达到上限及稳定标志；
- 地图 PK／其他玩家交互、GM／举报提示。

因此后续研究重点应是“识别并提醒游戏内辅助战斗是否健康运行”，而不是复刻战斗 AI。

### 7.4 魔物讨伐／图鉴

启燃测试按地图和魔物记录击杀数并给阶段奖励。攻略画面示例出现数十到数百的阶段目标，长线目标可能更高。来源：[Day2 录像](https://www.bilibili.com/video/BV1GqTK6oE4n/) `TEST-B`

需要采样：地图选择、魔物列表、当前数／目标数、奖励可领状态、疲劳后是否仍计数、组队击杀归属。

## 8. 世界地图、传送与组队

### 8.1 地图与传送

玩家一手资料显示每张地图有卡普拉传送，蝴蝶翅膀近似随身传送入口；Day2 录像还展示地图选择。`TEST-B`

不能假设开放世界能靠单一“点击目标任务”到达任何地方。跨图过程至少可能包含地图页、传送点、费用／道具确认、加载屏、频道和落点偏差。

### 8.2 队伍

当前测试资料显示有：

- 建立队伍、建立团队、寻找队伍；
- 世界／区域招募与自由加入；
- 队伍语音；
- 测试团队上限曾达到 40 人；
- 队友击杀可能给各自独立挂机收益。

这些能力都涉及真实玩家协作，首期只做状态识别和人工提示，不自动招募、踢人、跟队或发言。

## 9. MVP、裂隙与多人副本

### 9.1 野外 MVP

启燃测试观察：

- 日常曾要求参与多个 MVP；
- 对 Boss 造成有效参与可获得基础抽奖机会；
- 排名、首刀／尾刀可能关联额外奖励；
- 玩家反馈重生可能约一小时；
- 录像显示多人集中、Boss 技能、排名／奖励结算页。

来源：[恶魔波利短录像](https://www.bilibili.com/video/BV1hG7G6eEoE/)、[黄金虫录像](https://www.bilibili.com/video/BV1yp7Y67Eko/) `TEST-B`。

MVP 具有争抢、公平性、死亡和队伍影响，当前及未来首期默认排除自动化；研究只记录入口、倒计时、参与和结算状态。

### 9.2 残响裂隙／嘉奖宝库

测试攻略称残响裂隙按固定周期刷新，单队进入，完成后消失；Day2 画面展示地图／时段／每周宝箱等规则。`TEST-B`

需要国服确认：刷新是全服还是个人、入口消失条件、队伍人数、周上限、失败能否重试、跨线和抢占规则。

### 9.3 五人副本

旧测试副本卡片明确显示五人副本、人数要求、奖励和当日次数：[副本入口帧](../../research/evidence/video/day1-guide-bv1yqtk6oekk/frames/0409-five-player-dungeon.png)。玩家攻略建议传统的 1 坦、1 治疗、3 输出，并展示匹配、Boss 走位、队内装备拍卖和通关奖励。`TEST-B`

即使普通本可局部使用游戏内辅助，高难本录像已显示圆形、扇形、直线、矩形、网格 AOE、阶段血条和集合／分散等机制。不能设计成“开始自动战斗后只等结算”。

困难五人本还提供了明确的死亡与团灭样本：[困难蛮荒五人本录像](https://www.bilibili.com/video/BV1WzTn6QEkE/) `TEST-B`

- 约 02:06、12:18：个人死亡后画面变暗、技能栏消失并显示等待复活；
- 约 12:34：队友复活邀请带倒计时及“拒绝／同意”；接受后原地复活，共享复活数减少；
- 约 02:29：团灭后出现约 30 秒重整页，包含“放弃／再战”；
- 再战后进入全队准备／投票和加载，Boss 恢复至 100%，队伍及共享复活数重置；
- 约 26:22：胜利后先展示奖励，再返回副本场景，不等于已经退出。

一条 59 秒 TEST-B 十人副本 [Twitch Clip](../../research/evidence/video/twitch-clip-test-b-raid-dead-wait-g93cchbtrszole42/manifest.json)又显示：玩家从 Clip 开始到结束都保持画面变暗、技能栏消失和“等待复活”，而队友与 Boss 战继续。这只把个人死亡等待态交叉验证到十人本；录像没有死亡触发或复活结尾，不能扩展为野外复活规则。

PIONEER-A [印尼语十人本长直播](../../research/evidence/video/pioneer-ten-player-revive-bv1d4t8zseqw/manifest.json)进一步提供旧副本的完整队友复活链：存活时 `Kesempatan Respawn: 2`；死亡后画面变暗、技能栏消失并出现小幽灵和 `SOS`；队友邀请含 `Tolak／Setuju`；指针位于同意后相邻帧恢复 HUD，再出现明确成功提示，次数降到 `1`。Boss 血量在前后仍约 45%，不是团灭重置。该事实说明接受队友复活可能消耗有限资源，自动接受必须保持人工门；资源归属和国服规则未知，且旧副本链仍不能外推开放世界自身复活。

另一条 TEST-B 长评在 `544.90s` 直接显示[生存竞争模式救护车队友复活提示](../../research/evidence/video/test-b-long-review-bv1rrmw6qeom/frames/0544.90-survival-teammate-revive-prompt.png)：弹窗含身份牌样式图标和单个“复活”按钮。画面没有点击、资源扣除或队友恢复；它证明的是存活玩家复活队友的模式交互，绝不能替代玩家自身野外死亡页。

这些至少是四种场景，而不是一个通用“复活弹窗”：

```text
DungeonDeadWait → ReviveInvite → Fighting
PartyWipe → RetryVote → Loading → BossReset
Victory → BaseReward → Result／MVP → TeamAuction → ExitAvailable
```

高难本默认应提醒人工接管；自动接受复活、发起再战、投票或离开都不能从单一按钮模板推导。

### 9.4 十人 RAID“神之境界”

官方公开四个 Boss：

| Boss | 已公开机制概述 | 自动化判断 |
|---|---|---|
| 伊丝缇 | 同色／异色泡泡、音符互动 | 多人协作，首期排除 |
| 伊尔莫 | 记忆挑战、颜色音符和对应占位 | 会影响队友，首期排除 |
| 奈莎 | 节奏试炼、全队同步 | 首期排除 |
| 弥尔寇 | 躲危险区、击破不同颜色乐器、按序启动乐谱 | 首期排除 |

来源：[官方玩法报道](https://gnn.gamer.com.tw/detail.php?sn=298481) `GL-A/B`、[29 分钟实机录像](https://www.bilibili.com/video/BV1CNKD6YE4s/) `TEST-B`。

伊尔莫攻略录像还显示玩家要读取自己当前音符颜色、在倒计时前进入对应颜色圈、满足圈内人数／颜色条件；误站可能弹出队友，换音符有冷却。[攻略录像](https://www.bilibili.com/video/BV1teNM6SEeM/) `TEST-B`

## 10. 生活职业、宠物与公会

### 10.1 生活职业

启燃测试攻略提到矿工、厨师、园艺师；[职业全览画面](../../research/evidence/video/life-professions-bv1qyt964ehc/frames/0347-life-profession-overview.png)也直接显示这三个正式 UI 标签。另一段连续实机在当前角色上确认第一职业厨师、第二职业矿工，两者均为 1 级 `0/5000`，并显示活力 `700/5000`：[职业槽与活力](../../research/evidence/video/life-mining-bv18h756kehz/frames/0950-life-profession-overview.png)。论坛中的“采药、制药、挖矿”更可能是功能链概括；国服仍需核对本地化、可选总数和第二槽规则。`TEST-B`

同一录像提供了完整操作片段：厨师的绿色药水配方有材料槽、数量步进器和活力消耗 `20`；野外资源直接标注“1 级矿脉”，单次采集进度为 `4.5s`；五次完成帧依次显示活力 `700 → 680 → 660 → 640 → 620 → 600`、矿工经验 `0 → 220 → 440 → 660 → 880 → 1100`。约两分钟后每日页明确显示生活玩法“消耗活力值 `100/100`、已完成”。证据：[绿色药水配方](../../research/evidence/video/life-mining-bv18h756kehz/frames/0960-green-potion-recipe.png)、[采矿进度](../../research/evidence/video/life-mining-bv18h756kehz/frames/1000-mining-progress-45s.png)、[第五次结果](../../research/evidence/video/life-mining-bv18h756kehz/frames/1028-mining-yield-cumulative.png)、[每日完成](../../research/evidence/video/life-mining-bv18h756kehz/frames/1150-daily-life-100-completed.png)。画面不能证明自动连采，应按玩家逐节点操作处理。

候选操作链：选择配方／采集物 → 检查职业等级、活力和工具／材料 → 导航到资源点或制作 → 执行一次 → 检查产物、活力和熟练度。旧文档把任务误写成 `4/5 → 5/5`；实际 UI 是按活力值累计的 `100/100`。国服仍未知目标值、职业重选、活力恢复、节点归属、失败和批量制作规则。详见[日常系统百科](07-daily-system-encyclopedia.md)。

### 10.2 宠物与精灵之塔

宠物系统含主战、支援、额外助战位置、孵化／养成与宠物塔。[阵容页](../../research/evidence/video/pet-system-bv14gtk6lelc/frames/0510-pet-main-support-slots.png)直接显示一个主战位、支援 1–3，并在支援 3 上显示 Base 50 门槛；[助战页](../../research/evidence/video/test-closeout-bv1ybny6feze/frames/0062-pet-support-five-slots.png)另显示助战 1–5 号位以及宠物稀有度、星级和名称。[孵化房页](../../research/evidence/video/pet-system-bv14gtk6lelc/frames/0210-pet-incubation-level-probability.png)直接显示房间等级、总熟练度和品质概率，但不证明升级／保底链，也不证明解说中的属性继承比例。上述均为 TEST-B，高风险孵化、升阶和抽取不应作为自动决策；助手候选仅限读取编队和塔层状态。

[精灵之塔连续父帧](../../research/evidence/video/twitch-vod-2804721854/manifest.json)进一步直接显示普通未通关、黄色选中未通关、绿色已通关勾三类楼层外观；荣誉榜中第 20 层奖励由橙色可领格变为绿色已领勾，第 30 层随后同样变化，并出现“宠物蛋 ×3”到账提示。正式裁图把楼层和奖励分成两个键，奖励前后使用同一坐标且不绑定具体物品。仍未知锁定／禁用、挑战胜负、次数、重置、扫荡、领取失败与满包结果，国服也必须重采。

### 10.3 公会

公开内容包括公会物资／商队、营火、狩猎挑战、公会 Boss、百人 GVE、GVG、语音和团队指挥。[TEST-B 公会活动页](../../research/evidence/video/test-closeout-bv1ybny6feze/frames/0092-guild-activity-calendar.png)还分别展示领地争霸战、抢亲大作战、公会联赛、自然之神伊尔玛塔和狩猎挑战卡片。固定时段、参与次数和奖励在测试期被压缩，必须以国服活动日历为准；这些定时、多人或竞争场景只用于识别并排除。

## 11. 交易、摆摊与队内拍卖

启燃测试存在个人摊位，上架界面显示摊位槽位、背包物品、税率、价格与货币：[摆摊帧](../../research/evidence/video/day1-guide-bv1yqtk6oekk/frames/0430-stall-listing.png)。五人本结束还可能对队内装备拍卖，并把 Zeny 分给其他成员。`TEST-B`

交易动作不可逆且影响经济；自动定价、扫货、抢购、倒金和多账号转移均不在设计范围。即使未来获得某种测试授权，也必须有单独的交易许可和人工确认门，本项目默认仍排除。

## 12. 背包与快捷用药

TEST-B 现在已有两个清晰背包容量基准：[空背包 `0/300`](../../research/evidence/video/twitch-vod-2804892798/frames/0445.00-inventory-capacity-empty-0-of-300.jpg)和[正常背包 `36/300`](../../research/evidence/video/twitch-vod-2804807809/frames/18092.00-inventory-capacity-normal-36-of-300.jpg)，并已保存 HUD 背包入口裁图。它们证明容量采用“已用／上限”文本显示，但不能证明所有账号上限固定为 300，更不能回答接近满、真正满包、超额掉落去向或扩容。

[启燃测试心得](https://m.gamer.com.tw/forum/C.php?bsn=81475&snA=83)补充称最后一两天“卡片及灵魂残响背包已经接近满载”。该报告把风险缩小到两个分类背包，不能当成通用物品栏接近 `300/300`；帖子原图没有对应容量读数、满包反馈或下一掉落去向，因此只作为国服采样目标，不进入视觉模板。

[快捷用药连续片段](../../research/evidence/video/twitch-vod-2805739995/manifest.json)显示低血量自动使用开关、可调阈值、一个已配置槽和两个空槽；同窗药品数量由 `36` 变 `35`，随后尝试添加背包中没有的道具时出现明确反馈。该证据显著提高“由游戏内功能负责补药、外部系统只看护”的可行性，但仍不支持自动购买、补槽或把数量变化百分百归因于自动触发。

## 13. PVP、GVG 与百人玩法

GVG 包含破墙、内城／Boss、争夺华丽金属，以及攻城车、云梯、炮台、机甲等要素。[官方 GVG 报道](https://gnn.gamer.com.tw/detail.php?sn=294370) `GL-A/B`

这些玩法影响其他玩家、公会排名和资源，不应进入 MAA 首期，也不需要为它们设计识别后自动输入。公开视频只用于理解为什么需要全局 `CompetitiveMode` 安全场景：一旦识别到 PVP／GVG／排行榜页面，停止任何候选任务并提示人工接管。

## 14. 已知与未知边界

### 已有较充足证据

- PC 原生优先，国服首次测试仅 Windows；
- 鼠标点地／WASD 两种 PC 操作思路；
- UI 可缩放和移动；
- 游戏内建辅助战斗；
- 日常面板、活跃箱、野外挂机选择、五人本入口；
- 活跃箱可领 → 已领、高倍可用／运行／耗尽及耗尽时奖励通知继续、公会商队单批装载与第四批 `4/8 → 5/8` 发车状态边界、生活 `100/100` 完成；
- 背包 `0/300`／`36/300` 正常基准和快捷用药启用／数量变化；
- 六基础职业、当前展示的七个三转终点；
- 五人本、十人 RAID、MVP、生活、公会、摆摊等系统存在于旧测试；
- 高难多人内容有明显位置／颜色／同步机制。

### 仍不足以实现

- 国服进程名、窗口标题、窗口类、渲染和截图方式；
- 客户端专项协议与允许的研究范围；
- 默认分辨率、DPI、UI 缩放和可拖动窗口的持久化；
- 每个页面的高分辨率干净截图及多状态样本；
- 国服登录、排队、公告、更新、掉线和角色选择完整流程；TEST-B 已有启动器就绪至开放世界页面链，但仍缺认证、排队／维护、输入来源及异常保留；
- 野外死亡、真正满包、药品归零、低倍／疲劳、队伍异常；
- 各日常的国服次数、重置、奖励、前置条件和完成判据；
- 国服 OCR 字体、语言、反锯齿和主题变化；
- 暂停／恢复后各玩法的可靠重入点。

这些未知项就是 8 月采样计划的输入，不应被“看起来像旧 RO”之类推测填补。
