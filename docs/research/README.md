# 调研文档路线

本目录最终应回答五个问题：

1. RO3 每日要求玩家重复做什么？
2. 其中哪些工作已有游戏内自动寻路/自动战斗，MAA 只需编排和看护？

4. 哪些行为涉及消费、交易、竞争或封号风险，必须禁用或人工确认？
5. 2026 年 8 月国服首测需要录哪些画面，才能把推测变成可测试实现？
