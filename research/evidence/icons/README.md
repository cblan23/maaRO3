# 图标与 UI 状态裁图证据

本目录保存从已校验原始关键帧精确裁出的最小视觉样本。它们用于离线分类、
建立国服采样清单和比对版本差异，不是可直接驱动客户端动作的模板包。

## 当前内容

截至 2026-07-28：108 张独立 PNG 裁图，覆盖 56 个机器键；105 张为
`direct_clear`，3 张为 `contextual_candidate`。其中 90 张属于 `TEST-B`、18 张属于
`PIONEER-A`；两个构建在目录字段中严格隔离。所有文件均已通过父图哈希、裁切坐标、
尺寸、裁图哈希和逐像素重建校验。

- `catalog.json`：每张裁图的图标键、状态、父图、来源、视频时间戳或静态图片序号、裁切坐标、
  是否缩放、污染说明、限制、SHA-256 与国服复验标记；
- `catalog.schema.json`：裁图目录的 Draft 2020-12 Schema；
- `crops/`：不缩放、不抠图、不生成内容的 PNG 精确裁区；
- 当前仅保存能从同项目 `TEST-B` 或显式隔离的 `PIONEER-A` 画面确认的状态。`可领` 与 `已领`、
  `普通` 与 `选中` 等状态不共用标签。

## 重新生成

```powershell
py -3 tools/research/crop_icon_evidence.py --update-derived
py -3 tools/validate_research.py
```

生成器先核对父图 SHA-256，再按目录中的 `x/y/width/height` 裁切；若声明缩放，
必须记录算法和目标尺寸。父图既可以是视频关键帧，也可以是有独立 Still Manifest
的论坛／文章原图。总校验器会逐像素重建每张裁图，验证它与声明的父图、
坐标和缩放完全一致，同时拒绝未登记文件。

## 使用边界

- 所有当前样本都带明确的 `build`，并标为 `recheck_in_cn_test: true`；PIONEER-A 样本禁止进入 TEST-B／国服模板集；
- 小尺寸、压缩、字体、颜色和位置都不能外推至 2026-08-27 国服测试；
- `contextual_candidate` 只能辅助人工复核，不能升级成确定业务状态；
- 原视频中的水印、字幕、主播画面或队伍浮层如果落入裁区，必须显式标记；
- 不从其他 RO 产品借图，也不使用生成式图片补齐缺失状态。
